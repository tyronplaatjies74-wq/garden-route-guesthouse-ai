# Garden Route Guesthouse AI

24/7 AI Concierge for guesthouses in the Garden Route.

## To sell to a new guesthouse:
1. Copy this folder
2. Edit ONLY `data/guesthouse.json`
3. Deploy to Render
4. Send owner the demo link

## Tools:
- get_guesthouse_info
- recommend_restaurant
- plan_day_trip
- ask_host
